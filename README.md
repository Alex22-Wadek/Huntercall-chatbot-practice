# Учебный чат-бот для обработки типовых обращений

Репозиторий содержит прототип чат-бота, разработанный в рамках технологической
(проектно-технологической) производственной практики по направлению
`09.03.03 Прикладная информатика`.

Проект демонстрирует простой подход к классификации пользовательских запросов
по ключевым словам. Бот распознаёт приветствие, вопросы об услугах и режиме
работы, создание обращения, запрос связи со специалистом и завершение диалога.
Если запрос не распознан, используется безопасный резервный ответ.

## Возможности

- обработка русскоязычного текстового ввода;
- нормализация регистра и буквы `ё`;
- определение намерения по ключевым словам;
- резервный сценарий для неизвестных запросов;
- передача сложного обращения специалисту;
- автоматические тесты основных сценариев.

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки не используются.

```bash
python chatbot.py
```

## Запуск тестов

```bash
python -m unittest -v
```

## Структура

- `chatbot.py` — основная логика и консольный интерфейс;
- `test_chatbot.py` — автоматические тесты;
- `README.md` — описание проекта.

## Ограничения прототипа

Бот не хранит контекст диалога и не подключён к CRM. Для промышленного
использования потребуются лемматизация, расширенная классификация намерений,
защищённые интеграции, мониторинг и регламент обновления базы знаний.

Проект не содержит реальных персональных данных, переписки клиентов или
внутренней информации организации.
